# SUME Enterprise Website Design Direction

## Project Goal
Design a premium corporate website for SUME positioned as an Enterprise Infrastructure Company, Data Center Infrastructure Partner, and Mission-Critical Facility Specialist.

## Design Personality
- Enterprise corporate professionalism
- Modern editorial layouts
- Infrastructure engineering credibility
- Investor-grade presentation quality
- Architectural and industrial aesthetics

## Visual Keywords
Enterprise, Corporate, Institutional, Editorial, Structured, Premium, Architectural, Technical, Confident, Minimal, Mission-Critical, Infrastructure

## Layout Philosophy
- Large white space
- Strong typography hierarchy
- Modular grid systems
- Large image blocks
- Editorial composition
- Clean information architecture

Rule:
60% White Space
20% Typography
15% Photography
5% Decorative Elements

## Design Language

Avoid:
- Glassmorphism
- Neon effects
- Cyberpunk aesthetics
- Excessive gradients
- Startup-style cards
- Floating UI everywhere

Prefer:
- Structured grids
- Architectural photography
- Industrial photography
- Strong alignment
- Corporate spacing

## Color System

Primary: #0058BE
Secondary: #0E243C
Accent: #E7F1FF

Neutral:
#191C1E
#424754
#6B7280
#C2C6D6
#F8FBFF

## Typography

Preferred:
Heading: IBM Plex Sans
Body: Source Sans 3

Alternative:
Heading: Sora
Body: Source Sans 3

## Grid System

12-column grid

Container Width: 1440px
Content Width: 1280px

## Photography Style

Use imagery focused on:
- Data Centers
- Corporate Architecture
- High-rise Buildings
- Generator Facilities
- Chiller Plants
- Monitoring Centers
- Engineering Planning
- BIM Models
- Critical Infrastructure

## Solutions Section

- Power & Energy
- Precision Cooling
- Monitoring & Security
- Integrated M&E

Each card should rely on photography first and text second.

## Pattern System

Use patterns sparingly:
- Particle wave
- Data flow wave
- Engineering grid
- Architectural line systems

Opacity: 5–10%

## CTA Section

Large Headline
Short Supporting Text
Primary CTA

Example:
Let's engineer your infrastructure.

From mission-critical power systems to data center environments, we build infrastructure designed for performance, reliability, and uptime.

## Website Feeling

Enterprise Infrastructure Company
+ Consulting Firm
+ Public Company Investor Relations Website
+ Data Center Industry Leader

Result:
A premium enterprise company profile that communicates trust, scale, capability, and long-term partnership.
